Hai, saya Ardhika — seorang Web Developer dengan ketertarikan kuat pada pengembangan aplikasi web yang rapi, efisien, dan andal. Saya telah mempelajari dan membangun berbagai proyek web selama kurang lebih 3 tahun, mulai dari company profile, landing page, hingga sistem informasi dan dashboard admin.
Saya percaya bahwa website yang baik tidak hanya terlihat menarik, tetapi juga memiliki struktur kode yang jelas, mudah dipelihara, dan siap dikembangkan. Saat tidak sedang menulis kode, saya menghabiskan waktu untuk memperdalam Laravel, JavaScript, dan praktik terbaik pengembangan web modern.
